ksmbdzzer — KSMBD Write-Side LPE Fuzzer

trace-args/ret (kcov_dataflow) + libFuzzer + privilege bypass detection

Architecture

Findings

Finding 1: Exclusive lock without WRITE access (MS-SMB2 3.3.5.14)
Finding 2: DELETE_ON_CLOSE without DELETE access (MS-SMB2 3.3.5.9) — unauthorized file deletion

Usage

python3 ksmbdzzer.py fuzz -t 5h -procs 2 -target write -sniper-time 60

-t 5h: total runtime (graceful shutdown)
-sniper-time 60: seconds per sniper per round (higher = deeper corpus, increase as budget allows)
-target write: raw_write + dacl + compound + mt_race + read_after_write
